Ce programme compare les prix de 3 boutiques (Marché Lagune, Baobab Shop, Comptoir Ivoire) pour savoir laquelle est la moins chère.

Le programme foctionne comme suite:
-Il lit les fichiers des 3 boutiques.
-Il nettoie les noms et les prix (majuscules, espaces, prix vides).
-Il compare les prix de chaque produit.
-Il dit quelle boutique est la meilleure.

le programme se lance avec: python analyse.py

et un une application console qui presente avec 6 menu
1. Charger et nettoyer les données
2. Comparatif des prix (et export CSV)
3. Synthèse : quelle boutique est la meilleure ?
4. Panier de rentrée
5. Historique : Black Friday
6. Chercher un produit
0. Quitter


La boutique la moins chère est **Comptoir Ivoire**.

Fichiers

- `analyse.py` : le programme
- `donnees` : les fichiers de données
